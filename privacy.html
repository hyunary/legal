시행일: 2026년 5월 8일  |  버전 1.0

4. 개인정보의 제3자 제공

서비스는 원칙적으로 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만, 아래의 경우는 예외로 합니다.

  • 이용자가 사전에 동의한 경우
  • 법령에 의해 제공이 요구되는 경우
  • 매칭 성사 시 고용주에게 제공되는 정보: 구직자의 이름(닉네임), 연락처(선택 동의 시), 체크인·체크아웃 기록. 이 경우 이용자에게 사전 고지 후 동의를 받습니다.

5. 개인정보 처리 위탁

서비스는 원활한 운영을 위해 아래와 같이 처리 업무를 위탁합니다.

수탁 업체위탁 업무보유 기간
Supabase, Inc. 데이터베이스 저장·관리 (미국 소재 서버) 서비스 이용 기간 또는 위탁 계약 종료 시
Anthropic, PBC AI 매칭 및 업무 가이드 생성 (Claude API) API 처리 후 즉시 삭제 (Anthropic 정책 준수)
Apple Inc. Push 알림 발송 (APNs) 알림 전달 후 즉시 삭제

해외 이전: Supabase, Anthropic은 미국 소재 서버를 이용합니다. 「개인정보 보호법」 제28조의8에 따라 이전되는 정보, 이전 국가, 이전 일시·방법, 이전받는 자 정보를 공개하며, 이용자는 이전을 거부할 권리가 있습니다. 거부 시 서비스 이용이 제한될 수 있습니다.

6. 이용자의 권리와 행사 방법

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

  • 열람권: 자신의 개인정보 처리 현황 조회
  • 정정·삭제권: 오류가 있는 정보 정정 요청 또는 삭제 요청
  • 처리 정지권: 개인정보 처리 일시 정지 요청
  • 동의 철회권: 수집·이용 동의 철회 (회원 탈퇴 포함)
  • 이동권: 보유 중인 정보를 기계 판독 가능한 형태로 제공 요청

행사 방법

  • 앱 내 설정 → 계정 관리 → 개인정보 요청
  • 이메일: privacy@tumsaealba.com

요청 접수 후 10일 이내에 처리 결과를 안내합니다.

7. 자동 수집 장치 (위치·카메라·알림)

위치 정보

  • 사용 목적: 근처 단기알바 공고 추천
  • 수집 시점: 앱 실행 중 공고 검색 시 (백그라운드 수집 안 함)
  • 서버 저장 여부: 저장하지 않음 (디바이스 내에서만 처리)
  • 거부 방법: iOS 설정 → 개인정보 보호 → 위치 서비스 → 틈새알바 → 안함

카메라

  • 사용 목적: QR 코드 출퇴근 체크인 인식
  • 수집 시점: 이용자가 체크인 버튼을 탭할 때만 활성화
  • 사진 저장 여부: 저장하지 않음
  • 거부 방법: iOS 설정 → 개인정보 보호 → 카메라 → 틈새알바 → 끔

Push 알림

  • 사용 목적: 새 공고·매칭 결과·고용주 메시지 알림
  • 동의: 앱 최초 실행 시 이용자 동의 획득 후 발송
  • 거부 방법: iOS 설정 → 알림 → 틈새알바 → 알림 허용 끔, 또는 앱 내 설정

8. 개인정보의 파기

보유 기간이 경과하거나 처리 목적이 달성된 개인정보는 아래 방법으로 파기합니다.

  • 전자 파일: 복원 불가능한 방법으로 영구 삭제 (Supabase 레코드 hard delete)
  • 출력물: 해당 없음 (서비스 특성상 출력 없음)

법령에 의해 보존이 필요한 정보는 별도 데이터베이스로 분리하여 보관하며, 다른 목적으로 이용하지 않습니다.

9. 개인정보 보호 조치

  • 암호화: 비밀번호는 bcrypt로 해싱 저장. 민감 정보는 전송 시 TLS 1.2 이상 암호화
  • 접근 통제: Supabase Row Level Security(RLS)를 통해 자신의 데이터만 접근 가능
  • 접속 기록: 시스템 접속 기록 보관 및 위·변조 방지 조치
  • 외부 공격 대비: 정기적 보안 취약점 점검 실시

10. 아동 개인정보 보호

본 서비스는 만 14세 이상을 대상으로 합니다. 만 14세 미만 아동의 가입은 허용하지 않으며, 만 14세 미만인 것으로 확인된 경우 즉시 계정을 삭제하고 수집된 정보를 파기합니다.
